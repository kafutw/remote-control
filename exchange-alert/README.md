# 💱 匯率警報器(美元/日圓/台幣)

自動盯匯率,到了適合換匯的位階就開 GitHub Issue 通知你(GitHub 會寄 email)。

針對兩個換匯方向設計:

1. **台幣 → 日圓**:日圓夠便宜的時候提醒(去日本玩、換日圓資產)
2. **美元 → 台幣**:美元定存到期或美元夠貴的時候提醒,把美元換回台幣

## 運作方式

- GitHub Actions 在**台北時間平日 09:30、13:30、17:30** 各檢查一次
- 匯率來源:優先用**台灣銀行牌告匯率**(即期買賣中價,最接近實際換匯價),抓不到時改用 open.er-api.com 國際中價
- 觸發警報時自動開 Issue,同一條件 2 天內不重複提醒(冷卻期,可調)

## 警報條件(可在 `config.json` 調整)

### 固定門檻

| 條件 | 門檻 | 意義 |
|---|---|---|
| 日圓甜甜價 | JPY/TWD ≤ 0.20 | 適合台幣換日圓 |
| 日圓超甜價 | JPY/TWD ≤ 0.195 | 歷史少見低點 |
| 美元對台幣偏高 | USD/TWD ≥ 32.0 | 可考慮美元換回台幣 |
| 美元對台幣高點 | USD/TWD ≥ 32.5 | 美元換回台幣好時機 |

### 動態偵測(創新高/新低)

累積至少 20 天資料後啟用,跟過去 90 天比:

- 日圓兌台幣**創 90 日新低** → 提醒(日圓變便宜了)
- 美元兌台幣**創 90 日新高** → 提醒(美元換回台幣變划算)

> 參考水位(2026 年 8 月初):USD/TWD ≈ 31.3、JPY/TWD ≈ 0.2005

## 怎麼調整

改 `config.json` 就好,不用動程式:

- `rules[].threshold`:各條件的門檻價
- `cooldown_days`:同一條件幾天內不重複提醒(預設 2)
- `lookback_days`:創新高/新低的回看天數(預設 90)

## 注意事項

- **排程只會在 repo 的預設分支上執行**,這個功能要合併進預設分支後才會開始自動跑
- 合併後也可以到 Actions 頁面手動按 **Run workflow** 立刻測一次
- 要收到 email,請確認 GitHub 通知設定有開啟 Issues 通知(自己 repo 的新 Issue 預設會通知)
- 每次檢查會把當天匯率寫進 `history.json`(由 workflow 自動 commit),累積資料供新高/新低判斷
