## 🔤 ABC 字母大考驗

給小朋友認識 26 個英文字母的練習遊戲 → [`alphabet.html`](./alphabet.html)。架構跟 [`multiplication.html`](https://kafutw.github.io/remote-control/multiplication.html)（乘法表大考驗）一樣：單一 HTML 檔、不需要網路、紀錄只存在裝置上，也可以加到 iPad 主畫面全螢幕開啟。

**設定 → 作答 → 結果 → 歷史**，四個畫面的流程也一樣：

1. **今天練什麼** — 🔤 字母（ABC 26 個）、1️⃣ 小一單字（45 字）、2️⃣ 小二單字（48 字）。題庫一律全部練，常錯的會多出現幾次；每一項各自累積獎牌（🥇🥈🥉 看最近 10 題的答對率），在「認識字母／認識單字」裡看得到。
2. **一輪幾題、每題幾秒** — 10／15／20 題；每題 20 秒／30 秒／**不限時**（預設 30 秒，選不限時就完全不倒數，讓他慢慢想）。
3. **怎麼出題** — 聰明出題（常錯的多出現）或平均出題。題型隨模式切換：

   **字母**（只練字母本身，不考拼單字）
   - 🔊 **聽聲音** — 聽到哪個字母就選它
   - 🔠 **大寫找小寫** — 看 `A` 選 `a`
   - 🔡 **小寫找大寫** — 看 `a` 選 `A`

   **單字**（干擾選項優先挑同主題的，顏色配顏色、動物配動物）
   - 🔊 **聽發音選圖** — 聽到什麼點哪張圖，不用認字
   - 🖼️ **看圖選字** — 看圖片選英文字。選項旁邊有大顆的 🔊，**點喇叭只會念那個字、不算作答**，可以四個都聽過再選
   - 🔡 **看字選圖** — 看英文字選圖片，附「🔊 再聽一次」
   - 🈶 **看中文選字** — 看中文選英文字，選項一樣可以點來聽
   - 🔤 **填字母** — 克漏字：看圖聽發音，補上缺的那個字母（`b＿ll`、`＿ight`）。挖哪個位置隨機，選項是四個字母：母音配母音，子音挑形狀容易混的（`b` 配 p/r/d）

   家人這類「一張圖認不出是誰」的字（👧 和 👦 就是同一顆臉換髮型，👶 也可能是女生）**不會出圖片題**，自動改考聽發音或中文對應；筆類、車類、天空類這些圖案相近的，也不會在圖片題裡互相當選項。中文一律標注音。
4. **聲音怎麼念** — 在右上角的 🗣️ 裡（任何畫面都叫得出來，遊戲中也可以）：朗讀開關、口音（**預設挑美式英語 en-US**，找不到才退而求其次）、語速（很慢／慢／正常）、語調（低／中／高）、答對後要不要再念一次，以及試聽與音效測試。

**卡關提醒**（歷史畫面裡設定）：連續答錯 3 或 5 題就跳出來讓他喘一口氣，可以選「再試一次」或「今天先到這裡」。說法預設**自動升級**——前兩次好好講（沒關係慢慢來／要不要先聽一次／休息一下也可以），還是一直崩潰就換促咪的（再拖下去就在浪費自己看電視的時間囉／你比烏龜還慢欸），每組句子輪流出；也可以固定「一直溫柔」或「一直促咪」。小孩卡住通常不是不會，是急了。

**太吵也提醒**（同一張卡）：開了之後，作答時會開麥克風**只量音量**——連續 3 秒超過門檻就跳同一個關心畫面，跳過後 90 秒內不再打擾。門檻分「很大聲（0.30）」和「有點吵（0.20）」，旁邊有即時音量條可以先測。**不錄音、不上傳、不判斷內容**，所以分不出是哭還是笑，弟弟大叫或電視開很大聲一樣會跳；一輪結束就把麥克風關掉。預設是關閉的。

**結算畫面的「要複習的」可以點**：點一下就念一次英文，停一秒再用中文語音念中文（cow → 一秒 → 乳牛），字母則是「u → umbrella → 雨傘」。

作答畫面**固定在一屏內、不能捲動**（考試時不會不小心滑掉），題卡和選項會依螢幕高度自己壓縮。每題倒數（或不限時）、答錯會把正確答案和單字圖片亮出來念一次；結算給正確率、破紀錄提示、獎牌升級、要複習的字母，還可以用注音按鈕記錄今天練得順不順。獎牌門檻是 🥉 70%、🥈 80%、🥇 90%；**整輪 100% 全對會放全螢幕煙火**（canvas 畫的，沒有額外檔案）。歷史畫面看得到最近 12 次成績、每天練幾輪、哪幾個字母最熟／最需要加強，以及用眼提醒（練滿 20 或 30 分鐘就跳出休息畫面）。

另外有一個 **認識字母** 的模式：26 格字母表，點開字母卡看大小寫、發音（`A` 唸 `/æ/`）、代表單字和圖片，學會了按 ⭐。

**先選練什麼，再選單字從哪來**

第 1 張卡先選 **🔤 練字母**（26 個，永遠是完整的）或 **🔠 練單字**；選了單字才會出現「單字從哪裡來？」：

- **📚 都要**（預設）— 兩邊的字都收，124 個。
- **🏫 教育部** — 只出**國中小基本英語字彙 1200 字**表內的字，82 個（逐字比對過）。
- **🅷 何嘉仁** — 照 Fun World 1–4 冊各單元的單字表，**共 56 字**：小一上 FW1（a–m）17 ＋ 小一下 FW2（n–z）18 ＋ 小二上 FW3 新教 10 ＋ 小二下 FW4 新教 11。四冊一起練，不分冊（小二兩冊主要是複習小一，只有 ★ 標的才是新字）。
- 沒有做 **GEPT Kids** 這個選項：它的字表 PDF 在這個環境連不上（網路政策擋掉），無法逐字驗證誰在表內，做成篩選條件會是假的。分級時參考的是它公開的**主題結構**，不是字表本身。

**單字來源**

- **字母的代表單字**：26 個全部照**何嘉仁 Fun World 課本**內頁（「我會唸字母和單字」單元）——apple／book／cat／dog／egg／fish／goat／hen／insect／jet／kite／lion／monkey／net／ox／pig／quilt／red／sun／toy／umbrella／vest／watch／box／yo-yo／zoo。不跟著單字的教材來源換。其中 `jet`、`net`、`quilt`、`yo-yo` 不在教育部 1200 字表內。X 開頭課本用的也是字尾有 x 的 `box`。
- **何嘉仁的 56 個單字**：照課本各單元的單字表收的，不是字母頁的延伸補充區。
  - 小一上 FW1（17）`apple, ant, book, bird, cat, cup, dog, egg, elephant, fish, goat, hen, insect, jet, kite, lion, monkey`
  - 小一下 FW2（18）`net, nose, ox, pig, ball, sheep, quilt, red, sun, yellow, toy, umbrella, vest, watch, window, box, yo-yo, zoo`
  - 小二上 FW3 新教（10）`duck, fan, girl, boy, hat, igloo, jam, key, lamp, mom`
  - 小二下 FW4 新教（11）`octopus, pencil, queen, rabbit, snake, turtle, up, down, van, fox, zebra`
- **小一／小二單字表**：台灣低年級英語**沒有全國統一字表**——十二年國教課綱的英語文從**小三**才開始，一二年級屬於各縣市的彈性學習課程，教什麼由各校決定。所以這裡的分級是參考 GEPT Kids 主題字表、宜蘭員山國小的一二年級各 50 字，再對照教育部 1200 字挑出來的，**不是任何出版社的官方清單**。何嘉仁的完整單字索引不對外公開，在課本／習作最後的 Word List 和附贈的單字小卡片裡。

小地方：手機請把靜音鍵關掉才聽得到聲音；有鍵盤的話直接按鍵盤上的字母也可以作答；支援深色模式。

## 📖 國語大考驗

給小學一到六年級認生字、練注音的練習遊戲 → [`chinese.html`](./chinese.html)。架構跟 [`alphabet.html`](https://kafutw.github.io/remote-control/alphabet.html)（ABC 字母大考驗）、[`multiplication.html`](https://kafutw.github.io/remote-control/multiplication.html)（乘法表大考驗）一樣：單一 HTML 檔、不需要網路、紀錄只存在裝置上，也可以加到 iPad 主畫面全螢幕開啟。**設定 → 作答 → 結果 → 歷史**四個畫面、獎牌、卡關提醒、用眼提醒、全對放煙火，都跟另外兩個一樣。

### ⚠️ 先講清楚：字表不是康軒的課次

原本要照[教育百科的生字詞彙表](https://pedia.cloud.edu.tw/Bookmark/Textword?category=%E5%9C%8B%E8%AA%9E&year=114_2&degree=1&press=%E5%BA%B7%E8%BB%92%E7%89%88)（康軒版）逐課抓，但這個開發環境的網路政策把 `pedia.cloud.edu.tw` 擋掉了（其他外部網站也一樣），沒辦法逐字核對，**掛康軒的名字會是假的**。所以內建的 290 個字是照「常用度和筆畫難易」自己分的級，一到六年級各 40～70 字，**不等於康軒任何一冊的生字表**。

要照課本練，用首頁的 **✏️ 我的生字**：把課本、聯絡簿、生字簿上的字直接貼進去（一整課的生字或語詞都行，程式自己把中文字挑出來），按「存起來」就變成題庫。查得到的字會自動補上注音、部首、筆畫和語詞；查不到的字也留著，用聽發音的方式認字。想要真的康軒課次，把那個網頁上的生字表貼給我，我再併進字表裡。

注音、部首、總筆畫依教育部標準字體（艹 算 4 畫、辶 算 4 畫），跟課本和字典的數法一致；沒把握的兩個字（鄉、響）筆畫留白，**數筆畫的題目就不會考它們** —— 寧可少考一題，也不要教錯畫數。

### 怎麼玩

1. **今天練什麼** — 📖 生字、ㄅ ㄅㄆㄇ、✏️ 我的生字。選生字或 ㄅㄆㄇ 再選年級（一～六），以及「只練這個年級」或「累積複習」（一年級到這裡全部，六年級累積就是 290 個字）。
2. **題型**（生字，選「都出」會輪流換）
   - 🔤 **看注音選字** — `ㄏㄨㄚ` → 花
   - 🔡 **看字選注音** — 花 → `ㄏㄨㄚ`。干擾選項是**同一個音換聲調**、換成同部位的聲母（ㄅㄆㄇㄈ）、換成容易混的韻母（ㄢㄤㄣㄥ），專門練那幾個分不清楚的
   - 🔊 **聽聲音選字** — 只有聲音，看不到字；聽不到可以按「換個問法」，答案不變
   - 📝 **語詞填空** — 「＿朵」要填哪個字。這題的干擾選項**故意放同音字**，練的就是錯別字
   - 🧩 **找部首** — 花的部首是艸（艹），選項優先挑形狀容易混的（艸／竹／禾、水／冫、心／手）
   - ✏️ **數筆畫** — 這個字幾畫
3. **ㄅㄆㄇ 的題型** — 🔊 聽詞找聲母（「爸爸」是ㄅ還是ㄆ）、🔊 聽詞找韻母（ㄢ ㄤ ㄣ ㄥ 分得出來嗎）、🔤 拼拼看是哪個字。聲母的選項只從同一組發音部位裡挑（ㄅㄆㄇㄈ、ㄉㄊㄋㄌ、ㄍㄎㄏ、ㄐㄑㄒ、ㄓㄔㄕㄖ、ㄗㄘㄙ），韻母也是配成容易搞混的一組。
4. **一輪幾題、每題幾秒** — 10／15／20 題；每題 20 秒／30 秒／**不限時**（預設 30 秒）。
5. **聲音怎麼念** — 右上角 🗣️ 裡：朗讀開關、口音（**預設挑臺灣的國語 zh-TW**，大陸和香港的聲音預設不列出來，要看得自己勾）、語速、語調、答對後要不要再念一次，以及試聽與音效測試。單獨念一個字容易念成破音字的另一個音，所以念的時候都是「字＋語詞」（花・花朵）。

字一律用**楷體**顯示（BiauKai／標楷體／DFKai-SB），跟課本、生字簿上的形狀一樣。答錯會把整個字攤開來：字、注音、部首、筆畫、語詞一次看到並念一次。另外有 **認識生字** 模式：一格一個字（字在上、注音在下），點開看部首、筆畫和語詞，學會了按 ⭐。

其餘（獎牌 🥉70%／🥈80%／🥇90%、全對煙火、歷史紀錄、每天練幾輪、最熟／最需加強的字、用眼提醒、卡關提醒的溫柔與促咪）跟 ABC 字母大考驗一模一樣。有鍵盤的話按 **1～4** 可以直接選選項。
