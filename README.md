### 🔧 tools／均線跌破統計

想知道「這檔歷史上跌破季線幾次、每次跌破後通常怎麼走」，用這兩支腳本（需要 Node 18 以上）：

```bash
# 1. 從證交所抓歷史日線（一個月一包，抓 10 年約 8 分鐘）
node tools/fetch-twse.mjs 2330 2015 -o 2330.csv

# 2. 統計跌破均線的次數與後續報酬分布
node tools/ma-analysis.mjs 2330.csv --ma 60      # 季線
node tools/ma-analysis.mjs 2330.csv --ma 240     # 年線
```

`ma-analysis.mjs` 也吃你自己準備的 CSV，只要有「日期」和「收盤價」兩欄就行（證交所、Google 試算表、券商匯出的格式都可以，民國年也認得）。它會把**假跌破**（幾天內站回）和**有效跌破**（連續 3 天以上收在均線下）分開統計。
