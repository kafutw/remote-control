## 🔤 ABC 字母大考驗

給小朋友認識 26 個英文字母的練習遊戲 → [`alphabet.html`](./alphabet.html)。架構跟 [`multiplication.html`](https://kafutw.github.io/remote-control/multiplication.html)（乘法表大考驗）一樣：單一 HTML 檔、不需要網路、紀錄只存在裝置上，也可以加到 iPad 主畫面全螢幕開啟。

**設定 → 作答 → 結果 → 歷史**，四個畫面的流程也一樣：

1. **要出什麼題** — 見下一點。26 個字母一律全部練，常錯的會多出現幾次；每個字母各自累積獎牌（🥇🥈🥉 看最近 10 題的答對率），在「認識字母」的字母表上看得到。
2. **一輪幾題** — 10／15／20 題，每題 20 秒。
3. **怎麼出題** — 聰明出題（常錯的字母多出現）或平均出題。這個 App 只練字母本身，不考拼單字：
   - 🔊 **聽聲音** — 聽到哪個字母就選它
   - 🔠 **大寫找小寫** — 看 `A` 選 `a`
   - 🔡 **小寫找大寫** — 看 `a` 選 `A`
4. **聲音怎麼念** — 在右上角的 🗣️ 裡（任何畫面都叫得出來，遊戲中也可以）：朗讀開關、口音（**預設挑美式英語 en-US**，找不到才退而求其次）、語速（很慢／慢／正常）、語調（低／中／高）、答對後要不要再念一次，以及試聽與音效測試。

作答時每題倒數 20 秒、答錯會把正確答案和單字圖片亮出來念一次；結算給正確率、破紀錄提示、獎牌升級、要複習的字母，還可以用注音按鈕記錄今天練得順不順。歷史畫面看得到最近 12 次成績、每天練幾輪、哪幾個字母最熟／最需要加強，以及用眼提醒（練滿 20 或 30 分鐘就跳出休息畫面）。

另外有一個 **認識字母** 的模式：26 格字母表，點開字母卡看大小寫、發音（`A` 唸 `/æ/`）、代表單字和圖片，學會了按 ⭐。

**單字來源**：26 個代表單字都取自教育部「國中小基本英語字彙 1200 字」（十二年國教課綱語文領域－英語文，附錄五「參考字彙表」中加底線的 1200 字），挑清單裡最具體、能用圖案表達的名詞。要注意官方只規定「國小畢業至少會應用 300 個字詞」的**數量**，並沒有指定是哪 300 個，也沒有小一小二的官方字表（全國課綱從小三才排英語，台北、新北、台中等縣市在小一小二用彈性課程先教）。X 開頭在官方清單裡沒有任何字，所以用字尾有 x 的 `box`（清單內另有 fox、six、ox）。

小地方：手機請把靜音鍵關掉才聽得到聲音；有鍵盤的話直接按鍵盤上的字母也可以作答；支援深色模式。
