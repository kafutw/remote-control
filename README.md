# 品言的出門清單 🧸

寶寶出門的固定攜帶清單（過夜版）。每次出門前逐項打勾，帶齊就出發；回來後清空勾選，下次再用。

> 想要手機上點一點的版本？打開 [`checklist.html`](./checklist.html) — 可以直接點項目打勾、看進度、一鍵重置，勾選狀態會存在裝置上。
