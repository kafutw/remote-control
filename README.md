## 🔤 ABC 字母樂園

給小朋友認識 26 個英文字母的小遊戲 → [`alphabet.html`](./alphabet.html)（一樣是單一 HTML 檔，用瀏覽器打開就能玩，不需要網路）。

先選**玩法**，再選**要練哪幾個字母**（A–F／G–L／M–R／S–Z／A–Z），然後開始：

- **認識字母** — 26 格字母表，點下去會跳出字母卡：大小寫、發音（例：`A` 唸 `/æ/`）、代表單字和圖片，並用裝置內建的英文語音念出來。學會了按 ⭐，進度會存在這台裝置上。
- **字母大挑戰** — 一回合 10 題，隨機出三種題型：聽聲音選字母、看圖片補上開頭的字母、大寫配小寫。答錯可以再試，一次答對才算分；結算時給星星，並列出「再多看幾次」的字母。

小地方：手機請把靜音鍵關掉才聽得到聲音；有鍵盤的話直接按鍵盤上的字母也可以作答；支援深色模式。
