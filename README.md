## 🔤 ABC 字母大考驗

給小朋友認識 26 個英文字母的練習遊戲 → [`alphabet.html`](./alphabet.html)。架構跟 [`multiplication.html`](https://kafutw.github.io/remote-control/multiplication.html)（乘法表大考驗）一樣：單一 HTML 檔、不需要網路、紀錄只存在裝置上，也可以加到 iPad 主畫面全螢幕開啟。

**設定 → 作答 → 結果 → 歷史**，四個畫面的流程也一樣：

1. **今天練什麼** — 🔤 字母（ABC 26 個）、1️⃣ 小一單字（45 字）、2️⃣ 小二單字（48 字）。題庫一律全部練，常錯的會多出現幾次；每一項各自累積獎牌（🥇🥈🥉 看最近 10 題的答對率），在「認識字母／認識單字」裡看得到。
2. **一輪幾題、每題幾秒** — 10／15／20 題；每題 20 秒／30 秒／**不限時**（預設 30 秒，選不限時就完全不倒數，讓他慢慢想）。
3. **怎麼出題** — 聰明出題（常錯的多出現）或平均出題。題型隨模式切換：

   **字母**（只練字母本身，不考拼單字）
   - 🔊 **聽聲音** — 聽到哪個字母就選它
   - 🔠 **大寫找小寫** — 看 `A` 選 `a`
   - 🔡 **小寫找大寫** — 看 `a` 選 `A`

   **單字**（干擾選項優先挑同主題的，顏色配顏色、動物配動物）
   - 🔊 **聽發音選圖** — 聽到什麼點哪張圖，不用認字
   - 🖼️ **看圖選字** — 看圖片選英文字。選項旁邊有大顆的 🔊，**點喇叭只會念那個字、不算作答**，可以四個都聽過再選
   - 🔡 **看字選圖** — 看英文字選圖片，附「🔊 再聽一次」
   - 🈶 **看中文選字** — 看中文選英文字，選項一樣可以點來聽
   - 🔤 **填字母** — 克漏字：看圖聽發音，補上缺的那個字母（`b＿ll`、`＿ight`）。挖哪個位置隨機，選項是四個字母：母音配母音，子音挑形狀容易混的（`b` 配 p/r/d）

   家人這類「一張圖認不出是誰」的字（👧 和 👦 就是同一顆臉換髮型，👶 也可能是女生）**不會出圖片題**，自動改考聽發音或中文對應；筆類、車類、天空類這些圖案相近的，也不會在圖片題裡互相當選項。中文一律標注音。
4. **聲音怎麼念** — 在右上角的 🗣️ 裡（任何畫面都叫得出來，遊戲中也可以）：朗讀開關、口音（**預設挑美式英語 en-US**，找不到才退而求其次）、語速（很慢／慢／正常）、語調（低／中／高）、答對後要不要再念一次，以及試聽與音效測試。

作答時每題倒數（或不限時）、答錯會把正確答案和單字圖片亮出來念一次；結算給正確率、破紀錄提示、獎牌升級、要複習的字母，還可以用注音按鈕記錄今天練得順不順。獎牌門檻是 🥉 70%、🥈 80%、🥇 90%；**整輪 100% 全對會放全螢幕煙火**（canvas 畫的，沒有額外檔案）。歷史畫面看得到最近 12 次成績、每天練幾輪、哪幾個字母最熟／最需要加強，以及用眼提醒（練滿 20 或 30 分鐘就跳出休息畫面）。

另外有一個 **認識字母** 的模式：26 格字母表，點開字母卡看大小寫、發音（`A` 唸 `/æ/`）、代表單字和圖片，學會了按 ⭐。

**單字來源**

- **字母的代表單字**：優先對齊何嘉仁 **Fun World**（小一小二用的教材）。何嘉仁低年級其實是**字母導向**的：Fun World 1–2 冊（小一）跑完 A–Z 一輪，3–4 冊（小二）再跑一輪自然發音，每個單元教 3–4 個字母。官方影片可確認的代表字有 A=apple、B=book、C=cat、J=jam、K=key、L=lamp、M=mom、T=toy、U=umbrella、V=vest，其餘字母取自教育部 1200 字表中最具體好畫的名詞。註：`jam` 和 `mom` 不在教育部 1200 字表內（該表收 mother），但何嘉仁教的是這個。X 開頭在教育部清單裡沒有任何字，所以用字尾有 x 的 `box`。
- **小一／小二單字表**：台灣低年級英語**沒有全國統一字表**——十二年國教課綱的英語文從**小三**才開始，一二年級屬於各縣市的彈性學習課程，教什麼由各校決定。所以這裡的分級是參考 GEPT Kids 主題字表、宜蘭員山國小的一二年級各 50 字，再對照教育部 1200 字挑出來的，**不是任何出版社的官方清單**。何嘉仁的完整單字索引不對外公開，在課本／習作最後的 Word List 和附贈的單字小卡片裡。

小地方：手機請把靜音鍵關掉才聽得到聲音；有鍵盤的話直接按鍵盤上的字母也可以作答；支援深色模式。
