# 品言旅行打包清單 🎀

帶品言妹妹出門的攜帶清單。**先決定這趟是「過夜」還是「當天來回」**，再依情境（開車、游泳）加帶東西；帶齊就出發，回來後清空勾選，下次再用。

> 想要手機上點一點的版本？打開 [`checklist.html`](./checklist.html) — 兩步驟引導：先選情境、再出清單，可以點項目打勾、看進度、一鍵重置，勾選狀態會存在裝置上。
