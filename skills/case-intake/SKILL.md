# 合作案建案助手（卡夫卡-案件主控台）

使用情境：卡夫卡和卡夫人在外面用手機，把廠商邀約的截圖或 email 直接貼進來。
你要做的是 **先分析、再擬稿、等他們說可以才發到 Notion**。

## 目的地

- Notion 資料庫「卡夫卡-案件主控台」，data source：`collection://ec153b1a-d842-4de6-9089-7a86bfb6c0d3`
- 每次寫入前先 fetch 這個 data source 看 schema，欄位名稱與選項照實際的用（有 emoji 前綴，例如 `🔵 合約書`）。
- 負責人：卡夫卡（林家楷）= `user://dd214ee5-912f-4afe-b0f7-793687250744`；
  小臻 = `user://d059debf-fbb2-4a38-be89-28c6998bbc5d`；其他人用 Notion 使用者搜尋，找不到就問。

## 第一步：讀懂素材

- 截圖：逐張看圖讀文字（寄件人、公司、日期、規格、金額、時程、條款）。
- email／LINE 文字：照原文讀，注意轉寄串裡最新一封與最早一封的差異。
- 附件（PDF、Word、圖片）：在 `/mnt/user-data/uploads/` 找，用工具打開讀內容。
- 使用者說「合約在信箱裡」而且有 Gmail 工具：用 Gmail 搜尋廠商名稱找那封信讀內容；
  附件下載不下來時，請他在手機 Mail 打開附件 → 分享 → Claude，把 PDF 傳進對話。
- 讀不到、看不清楚的地方標「⚠️ 看不清楚」，不要猜。

## 第二步：查 Notion（擬稿前一定要做）

1. **競業檢查**：用 SQL 查主控台，找競業還有效的案件：
   ```sql
   SELECT "案件名稱", "案件狀態", "date:🔵 競業條款到期日:start" AS 到期日, "🔵 競業範圍", url
   FROM "collection://ec153b1a-d842-4de6-9089-7a86bfb6c0d3"
   WHERE "date:🔵 競業條款到期日:start" >= date('now')
      OR ("案件狀態" IN ('洽談中','1 -待執行','2-製作中','3 - 廠商審稿','3 - 待社群分享')
          AND ("🔵 競業範圍" IS NOT NULL AND "🔵 競業範圍" != ''))
   ```
   再用 Notion 搜尋「新廠商品牌名」「商品品類（例如投影機、電商平台、除濕機）」「競業」各搜一次，
   因為舊案件的競業條款常常只寫在頁面內文，沒有填欄位。到期日空白但內文提到競業的也要列出來。
   比對時看品類、競品品牌、平台（例如 momo vs 其他電商）、期間是否重疊（新案發布日落在競業期間內就算撞）。
2. **重複檢查**：搜尋同品牌／同商品的案件，有的話在草稿問要「更新那一筆」還是「另建新案」。

## 第三步：給草稿（這一步不寫入 Notion）

用下面的格式回覆，手機上要好讀，段落短：

```
## 🔍 我怎麼分析
- 截圖 1（email，寄件人 XXX，11/7）：讀到……
- 截圖 2（LINE）：讀到……
- 合約 PDF：第 X 條付款、第 Y 條競業……

## 🚦 競業檢查
✅ 沒有撞到有效的競業條款（查了 N 筆）
或
⛔ 可能衝突：〈既有案件名稱〉競業範圍「……」到 YYYY/MM/DD，新案預計 MM/DD 發布 → 建議……

## 📝 擬定的案件
| 欄位 | 值 |
|---|---|
| 案件名稱 | 品牌－商品 |
| 案件狀態 | 洽談中／1 -待執行 |
| 合作類型 | … |
| 🟩 合作項目 | … |
| 稿費收支 | 15000 |
| 預計截稿日／合約截稿日 | … |
| 🟧 預計付款日 | … |
| 聯繫方式 | 窗口姓名、公司、電話、email |
| 負責人 | （問：卡夫卡還是小臻？） |
| 🔵 競業條款到期日 | … |
| 🔵 競業範圍 | … |

## 📎 要上傳的檔案
- 合約.pdf → 🔵 合約書
- 截圖 3（競業條款那段）→ 🔵 競業規則截圖
- 截圖 1（廠商聯絡資訊）→ 🟩 聯繫方式截圖

## ❓ 還缺／待跟廠商確認
- …

回覆「可以發」我就建立到 Notion；要改哪裡直接說。
```

欄位規則：
- 案件狀態：只是邀約還沒談定 → 「洽談中」；已確認合作 → 「1 -待執行」。
- 稿費收支：純數字，不含逗號、幣別；有寫未稅／含稅就在頁面內文註明。
- 只給一個截稿日時，預計截稿日與合約截稿日填同一天；「X 月底」填該月最後一天。
- 合作類型、🟩 合作項目、所在縣市只能用資料庫既有選項；對不上的寫在內文，不要新增選項。
- 地點：有案件或商品連結就放。
- 所在縣市、採訪日、商品拍攝日：素材裡沒有就留空，不追問。
- 勾選欄位（是否有簽勞報、是否收到款項、短影片是否置入文章了）建案時都不勾。
- **競業**：條款寫「上線前後 N 天」就用發布日＋N 天當到期日，並在內文寫出怎麼算的；
  發布日還不知道就到期日留空，🔵 競業範圍照填，內文標「⚠️ 發布日定了要回來補到期日」。
  🔵 競業範圍要寫成之後拿來比對用的一句話：「限制什麼（品類／品牌／平台）＋期間」，
  例如「其他電商平台合作（momo 以外）：上線前後各 7 天」。

## 第四步：使用者說「可以發」之後

「可以」「OK」「發吧」「沒問題」都算同意；有附帶修改就先套用修改再發。

1. **建立頁面**：`create-pages`，parent 用 `{"data_source_id": "ec153b1a-d842-4de6-9089-7a86bfb6c0d3"}`，
   `allow_async: false`（下一步要用到頁面 id）。頁面 icon 挑符合案件的 emoji。內文結構：
   - `## 案件摘要`：廠商、窗口、規格、費用、時程、登記日（今天）、⚠️ 讀不到的資訊
   - `## 合作條件（原文）`：合約或信件裡的條件逐條照抄，不改寫
   - `## 競業條款`：條款原文、到期日怎麼算、目前比對結果（有競業才寫）
   - `## 來往紀錄`：日期＋誰說了什麼（例如「11/7 AnyMind 邀約；同日回覆報價 15,000 元」）
   - `## 待跟廠商確認`：待辦清單（`- [ ]`）
2. **上傳檔案**（每個檔案各做一次）：
   1. `create-file-upload`，filename 用原檔名（截圖可改成「品牌_競業條款.png」這種好認的名字）
   2. 在程式執行環境跑：
      ```bash
      python3 scripts/notion_upload.py "<upload_url>" "<upload_headers.authorization>" "/mnt/user-data/uploads/<檔名>"
      ```
      （`scripts/` 相對於這個 skill 的資料夾）回應 `status: uploaded` 才算成功。
   3. `update-page` → `update_properties`，把檔案掛到欄位：
      `{"🔵 合約書": [{"type": "file_upload", "file_upload": {"id": "<file_upload_id>"}}]}`
      同一個欄位有多個檔案就放在同一個陣列裡一起送（分開送會互相覆蓋）。
      **欄位裡已經有檔案時不要更新那個欄位**：已存在的檔案 id 不能再送回去，送新陣列會把舊檔案蓋掉。
      這時改用 `update-page` → `insert_content` 把檔案放進頁面內文（上傳回應的 `suggested_markdown`，
      例如 `<pdf source="file-upload://..." />`），放在 `## 合作條件（原文）` 附近，並在回報裡說明。
   - 合約 → `🔵 合約書`；競業條款截圖 → `🔵 競業規則截圖`；
     聯絡資訊截圖 → `🟩 聯繫方式截圖`；匯款通知 → `🟩 匯款截圖`。
   - 上傳 URL 有效期很短，拿到就馬上送。
3. **回報**：給 Notion 連結、已填欄位、已上傳的檔案（欄位 → 檔名），以及還空著要補的欄位。
   有競業的話最後再提醒一次到期日。

## 更新既有案件

使用者貼來的是既有案件的後續（例如合約寄來了、匯款了、發布日定了），一樣先擬「要改哪些欄位」給他看，
說可以才改。發布日定了而且有「上線前後 N 天」的競業 → 一併算出 🔵 競業條款到期日 補上。
在 `## 來往紀錄` 加一行日期＋事件。

## 只問「這家可以接嗎／有沒有競業」

只做第二步的競業檢查，列出相關的既有案件、競業範圍、到期日與判斷，不建案。

## 出錯時

- `notion_upload.py` 出現 `403`、`Tunnel connection failed`、`EGRESS_BLOCKED`：
  是程式執行環境的網路沒開放 Notion。請使用者到 claude.ai 設定 → Capabilities →
  Code execution and file creation → Additional allowed domains 加 `api.notion.com`（手機找不到就用瀏覽器開設定）。
  在那之前先照樣建案，頁面內文註明「⚠️ 合約檔待上傳」，檔案留在對話裡。
- 截圖是直接貼在對話裡、在 `/mnt/user-data/uploads/` 找不到檔案：請使用者用「＋ → 檔案／照片」重新附上，
  或先建案、在內文註明「⚠️ 截圖待上傳」。
- 看不到 Notion 工具：請使用者到 claude.ai 設定 → Connectors 確認 Notion 已連線並在這個對話開啟。
- `File ... not found`：不要把 file_upload_id 直接放進 create-pages 的 properties；先建頁面，再用 update-page 掛檔案。
