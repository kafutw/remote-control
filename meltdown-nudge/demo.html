meltdown-nudge

小孩卡關或崩潰的時候跳出來喘口氣的小元件。一個 JS 檔，沒有相依套件。

① 連續答錯就跳

這裡設連錯 3 次。按「答錯」三次看看。

目前連錯 0 次

② 太吵也跳

只量音量，不錄音、不上傳、不判斷內容。要 https（或 localhost）才有麥克風權限。

還沒開始聽

怎麼用

<script src="meltdown-nudge.js"></script>
<script>
var nudge = MeltdownNudge.create({
  missStreak: 5,                       // 連錯幾次跳一次
  noise: { level: 0.16 },              // 要聽音量才給，不給就不開麥克風
  tone: 'auto',                        // 先溫柔，鬧不停才促咪
  onResume: function () { nextQuestion(); },
  onStop:   function () { endRound(); }
});

nudge.miss();      // 答錯
nudge.hit();       // 答對，連錯歸零
nudge.listen();    // 開始聽（一定要在使用者手勢裡呼叫）
</script>

句子可以自己換：lines: { soft: [['🫂','沒關係，慢慢來']], fun: [['📺','哭哭浪費看電視時間喔']] }。 跳出來的那句話會用語音念，念完停一秒自己關掉繼續。
